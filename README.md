# CORK

A text-based adventure game inspired by ZORK.

---

## How to Play

### Windows

**Option 1 — Download the zip**

1. Download `CORK_windows.zip` from the root of the repository.
2. Extract the zip to a folder of your choice.
3. Run `CORK.exe` inside the extracted folder.

**Option 2 — Download the exe directly**

1. Navigate to `CORK/CORK_windows/` in the repository.
2. Download `CORK.exe` as a raw file.
3. Place it in its own folder and run it.

**Option 3 — Clone the repo**

1. Clone this repository: `git clone https://github.com/your-username/CORK.git`
2. Open the `CORK_windows` folder.
3. Run `CORK.exe`.

---

### Mac

**Option 1 — Download the zip**

1. Download `CORK_macbuild.zip` from the root of the repository.
2. Extract the zip to a folder of your choice.
3. Open `CORK_mac.app`.

**Option 2 — Clone the repo**

1. Clone this repository: `git clone https://github.com/your-username/CORK.git`
2. Open the `CORK_macbuild` folder.
3. Open `CORK_mac.app`.

> **Note for Mac users:** If macOS blocks the app because it's from an unidentified developer, right-click `CORK_mac.app` and choose **Open**, then confirm in the dialog.
